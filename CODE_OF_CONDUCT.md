# Community Code of Conduct

RouteSphere BonVoyage API Gateway aims to be a rigorous, welcoming engineering
project.
Participants must communicate respectfully, critique ideas and evidence rather
than people, state assumptions clearly, and help others work safely.

Unacceptable behavior includes harassment, discrimination, threats, sexualized
attention, deliberate intimidation, sustained disruption, publication of
private information, or retaliation against a good-faith report.

This standard applies in repository issues, discussions, reviews, project
events, benchmark publications, and other spaces where someone represents the
project. Maintainers may edit or remove content, close discussions, restrict
participation, or take other proportionate action when conduct conflicts with
this standard.

Report conduct concerns privately to <sales@routesphere.global> with the subject
`Community conduct`. Include only the context needed to assess the concern.
This address is not the security-vulnerability intake; suspected vulnerabilities
must follow [SECURITY.md](SECURITY.md).
